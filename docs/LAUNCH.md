## 界面和營運限制
- V1 商品採每商品一個庫存 SKU；可建立不同商品表示不同包裝，沒有多規格變體選擇器。
- 附件只接受安全再編碼的 PNG／JPEG，不提供任意 PDF／Office。商品／封面另支援 WEBP。
- 報表包含在線分頁、同條件 Excel 及 API totals；部分進階參數（category、assignee_id、merchant_id、campaign_id、bucket、sort）透過 query/API 使用，尚非所有參數都有專門選單。
- 財務及捐款交易沒有真實第三方連線；測試回調、測試收據及 sandbox outbox 不能用於正式收款。
- 沒有正式電郵驗證或密碼重設郵件，聯絡方式明示人工待核實；帳號恢復由受控管理流程處理。
- 法律頁是標示待審的說明草稿；不代表已通過法律審閱。
- 瀏覽器與 axe 檢查不能代替真實高齡使用者、讀屏或完整 WCAG 人工驗收。
